# Вариант 7 — справочник площадок Казани

Веб-интерфейс для просмотра и управления справочником площадок: название, район, адрес, координаты WGS84 и вместимость. Реализованы добавление, редактирование, удаление, поиск, фильтрация и сортировка.

## Запуск

Требования: Docker Engine и Docker Compose plugin.

1. При необходимости измените `PG_USER_PASSWORD` и `APP_PORT` в `.env`.
2. Из корня проекта запустите:

   ```bash
   docker compose up -d
   ```

3. Откройте [http://localhost:8080](http://localhost:8080) (или порт, заданный в `APP_PORT`).

При первом запуске Compose скачает backend `ghcr.io/nelkor/kazan-events:latest` и PostGIS, создаст БД `kazan_events`, дождётся готовности PostgreSQL и запустит фронтенд. По умолчанию `SEED_MODE=sample`: сервер наполнит пустую БД демонстрационными данными. Для пустого каталога задайте `SEED_MODE=empty` до первого запуска на новом томе.

## Работа с приложением

- **Список:** таблица показывает название, адрес, район, вместимость и координаты. Переключатель справа от заголовка меняет таблицу на карточки.
- **Поиск:** поле поиска фильтрует площадки по подстроке названия/описания.
- **Фильтры:** выберите район и наличие координат. Сортировка доступна по названию и вместимости.
- **Добавление:** нажмите «Добавить площадку», заполните обязательные поля и сохраните запись.
- **Редактирование:** кнопка с карандашом открывает форму с текущими значениями.
- **Удаление:** кнопка с корзиной запрашивает подтверждение. API физически удаляет площадку только если на неё не ссылаются мероприятия.
- **Координаты:** вводятся десятичными градусами WGS84: широта от -90 до 90, долгота от -180 до 180. Можно оставить оба поля пустыми; указывать только одно нельзя. Для заполненных координат доступна ссылка на OpenStreetMap.

Город в текущей версии API фиксирован: **Казань**. Район передаётся техническим кодом из справочника `/api/v1/meta/districts`, интерфейс показывает русские названия.

## Архитектура и API

- `frontend` — React + Vite, собирается в статические файлы и раздаётся NGINX.
- NGINX обслуживает интерфейс и проксирует `/api/v1/*` в контейнер `backend`. Браузеру не требуется знать внутренний адрес backend.
- `backend` — готовый образ `ghcr.io/nelkor/kazan-events`.
- `db` — PostgreSQL 17 с PostGIS 3.6 и постоянным Docker volume `postgres_data`.

Используемые методы:
- `GET /api/v1/venues` — список с `page`, `page_size`, `q`, `district_code`, `has_coordinates`, `sort`.
- `POST /api/v1/venues` — создание площадки.
- `PATCH /api/v1/venues/{id}` — частичное изменение.
- `DELETE /api/v1/venues/{id}` — удаление.
- `GET /api/v1/meta/districts` — справочник районов (коды и русские названия).
